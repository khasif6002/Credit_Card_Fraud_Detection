# credit-card-fraud-detection
Machine Learning based Credit Card Fraud Detection System using Random Forest Classifier with Streamlit deployment. This project includes EDA, feature engineering, fraud prediction, CSV upload-based detection, and downloadable prediction reports.

# Credit Card Fraud Detection

🚀 Live Demo:
https://creditcardfrauddetection-4vysz3qcaausye2nmyzpe6.streamlit.app

## Project Overview
This project uses a Random Forest Classifier to detect fraudulent credit card transactions.

## Features
- Fraud detection using Machine Learning
- CSV file upload
- Real-time predictions
- Downloadable prediction results
- Streamlit web application

## Technologies Used
- Python
- Pandas
- Scikit-Learn
- Streamlit
- Random Forest
